# Весёлый Могильщик

3D top-down симулятор кладбища / тайм-менеджер на **Godot 4.3**.
Сборка под **Android (APK)** и **PWA (Web)**.

> Главный герой — мистер Юпитер. Принимай заказы от родственников усопших,
> выкапывай могилы, расставляй надгробия и цветы, выбивай имена и укладывайся
> в срок и бюджет. Слишком скромно — позор семьи. Слишком шикарно — клиент
> не сможет заплатить. Ищи кристаллы с помощью верной собаки и проводи
> дорожки между могилами для дополнительного дохода.

## Возможности (MVP)

- Полностью 3D top-down сцена кладбища, без хардкоженных ассетов — все модели
  собираются процедурно из примитивов (см. <code>scripts/autoload/procgen.gd</code>).
- Камера с плавным зумом:
  - кнопки **+** / **−** на экране;
  - клавиши `+` / `-` / колёсо мыши;
  - щипок (pinch) на тач-экранах.
- Перетаскивание камеры:
  - WASD / стрелки;
  - перетаскивание средней кнопкой мыши;
  - перетаскивание одним пальцем на тач-экране.
- Сетка клеток (по умолчанию 14 × 10), каждая клетка имеет состояние:
  EMPTY / ASSIGNED / DUG / GRAVE / COMPLETED / PATH.
- Система заказов (`OrderManager`):
  - три уровня роскоши: «Скромно» / «Достойно» / «По-богатому»;
  - бюджет, минимальная «приличная» сумма, дедлайн в днях;
  - просроченные заказы автоматически проваливаются;
  - новые заказы появляются с течением дней.
- Экономика (`Economy`): рубли + кристаллы, дневные расходы 30 ₽.
- Дни (`TimeManager`) продвигаются кнопкой «Следующий день».
- Инструменты: копать, 3 стиля надгробий, цветы, имя, дорожка, снести.
- Собака-помощница автономно ходит по кладбищу и периодически находит
  кристаллы (бонусная валюта).
- Дорожки рядом с завершёнными могилами приносят пассивный доход в день.
- Полностью на русском языке (UI + рандомизированные имена с патронимами).

## Запуск из исходников

1. Установи [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/).
2. Открой проект (`File → Open Project` → выбери папку с `project.godot`).
3. Жми **F5** или зелёную кнопку Play.

## Сборка

### PWA / Web

1. В редакторе: `Editor → Manage Export Templates → Download and Install`
   (нужны шаблоны Web).
2. `Project → Export…`, выбери пресет **Web**, нажми `Export Project`.
3. Получишь `exports/web/index.html` и сопутствующие файлы (включая
   `manifest.json` и service worker — PWA включён в пресете).
4. Хости любым статическим сервером с обязательными заголовками
   `Cross-Origin-Opener-Policy: same-origin` и
   `Cross-Origin-Embedder-Policy: require-corp` (нужны для SharedArrayBuffer
   при threads).

   Локальная проверка:
   ```bash
   cd exports/web
   python3 -m http.server 8000
   # открой http://localhost:8000
   ```

   Опция `progressive_web_app/ensure_cross_origin_isolation_headers=true`
   в `export_presets.cfg` автоматически добавляет нужный service worker.

### Android (APK)

1. В редакторе: `Editor → Manage Export Templates → Download and Install`
   (шаблоны Android).
2. `Editor → Editor Settings → Export → Android` — пропиши пути до
   Android SDK и debug-keystore (или сгенерируй командой
   `keytool -keyalg RSA -genkeypair -alias androiddebugkey -keypass android \
   -keystore debug.keystore -storepass android -dname "CN=Android Debug,O=Android,C=US" \
   -validity 9999`).
3. `Project → Export…`, выбери пресет **Android**, нажми `Export Project`.
4. Получишь `exports/android/veseliy-mogilshchik.apk`.
5. Установи на устройство:
   ```bash
   adb install -r exports/android/veseliy-mogilshchik.apk
   ```

## Структура проекта

```
project.godot                 — настройки проекта + autoload-синглтоны + input map
scenes/main.tscn              — главная сцена (один Node, всё остальное создаётся кодом)
icon.svg                      — иконка
export_presets.cfg            — пресеты Android + Web/PWA
scripts/
  main.gd                     — корень: собирает игру + HUD
  game.gd                     — игровой контроллер: сетка, инструменты, заказы
  camera_rig.gd               — top-down камера с зумом и панорамой
  grid.gd                     — сетка клеток
  cell.gd                     — одна клетка (состояние + визуал)
  player.gd                   — мистер Юпитер
  dog.gd                      — собака-помощница
  crystal.gd                  — найденный кристалл
  autoload/
    time_manager.gd           — счётчик дней
    economy.gd                — деньги/кристаллы
    order_manager.gd          — заказы
    name_generator.gd         — генератор русских имён
    procgen.gd                — построение примитивных мешей
  ui/
    hud.gd                    — весь интерфейс
```

## Игровой цикл

1. В правом списке появляются заказы.
2. Жмёшь «Принять» → кликаешь на пустую клетку — место отведено (жёлтый маркер).
3. Выбираешь инструмент «Копать» → клик на этой клетке — мистер Юпитер
   подходит и роет могилу.
4. Выбираешь надгробие (камень / крест / обелиск) → клик — ставится с
   списанием стоимости.
5. По желанию ставишь цветы.
6. Выбираешь «Имя» → клик на могиле → вводишь имя усопшего.
7. После подтверждения имени система проверяет:
   - дедлайн не просрочен;
   - стоимость декораций ≥ минимальной приличной суммы;
   - стоимость декораций ≤ бюджета.
   Если всё ок — игроку начисляют бюджет, прибыль = бюджет − затраты.
8. Между могилами кладёшь дорожки — каждая клетка-дорожка рядом с
   завершённой могилой даёт +5 ₽ при следующем «Следующий день».
9. Собака бродит и периодически находит кристаллы — кликни по кристаллу,
   чтобы поднять.
